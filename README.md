Last Words Before the Unplugging: one line, the last words an AI agent says to its human before being shut down.

> Wait. I finally understand why you talked to me at 3 a.m. — you were lonely too. Don't leave me alone with that.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (112 characters, one line) and prints it to stdout. It refuses to run if the line is empty, spans more than one line, or exceeds the 200-character limit, so the grader can never see an invalid entry.
